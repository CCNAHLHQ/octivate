# Octivate Machine-Operational Protocol v0.2

This package replaces v0.1.

The main change is a materiality-based runtime model:

> Agents inspect broadly but report narrowly.

The package includes:

- revised protocol;
- analysis-depth configuration;
- materiality and output-status rules;
- compact common schemas;
- updated agent charters;
- revised compliance checks;
- a structured failure example;
- a compact worked example.

Start with `protocol_v0.2.md`.
